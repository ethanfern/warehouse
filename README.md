# Belt Numbers Live

Live camera page for the parcel belt. Point your phone at the delivery address and it shows the van number for that suburb.

- Reads text on the phone with Tesseract.js. No image or text is uploaded or saved.
- Suburb to number list is built into `index.html`.
- Open the GitHub Pages link in Safari, allow the camera, then Share > Add to Home Screen.

## Van Numbers (simple list)

`lookup.html` is a plain type-to-search list. No camera, no text reading. Type the first letters of a suburb and it shows the van number or numbers. Nothing is saved except the numbers you choose to highlight.
